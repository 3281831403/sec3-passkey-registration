用户注册通行密钥时，攻击者把挑战换成自己事先准备好的一串，注册上来的公钥就成了他的：挑战必须由服务端签发、只对发起注册的用户有效且只能用一次；来源标识与预期必须完全一致，多一个字符也不行；依赖方标识必须与预期完全一致；公钥必须能被解析且算法必须在支持列表内；凭据标识必须全局唯一，不得覆盖任何已有凭据；注册结果必须绑定当前已认证的用户；证明校验不通过时不得写入存储；批量注册中每个请求各自独立，不得共用挑战或状态。不变量：同一挑战第二次使用必然失败；任何来源标识不符的注册都被拒绝。
